# Task: Domains Module

## Requirements
1. Build the `/domains` view with Top Navigation.
2. Fetch and display data from the `domains` Convex table.
3. Implement a "Add Domain" button that opens a Modal.
4. **UI Logic (Expiration Status):**
   - Red: `Expire Date` < Current Date.
   - Yellow: `Expire Date` is within 1 month of Current Date.
   - Green/Default: Safe (> 1 month).
